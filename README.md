# Processo Code GitHub

## Sobre o projeto

Este projeto apresenta, de forma prática e organizada, o processo de configuração e utilização de Python, VS Code, Git e GitHub.

## Objetivo

Demonstrar como preparar um ambiente de desenvolvimento, criar um projeto em Python, utilizar um ambiente virtual, controlar versões com Git e publicar o projeto no GitHub.

## Tecnologias e ferramentas

- Python
- VS Code
- Git
- GitHub
- Pandas
- Matplotlib
- OpenPyXL
