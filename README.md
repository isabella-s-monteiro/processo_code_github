# Processo Code GitHub

## Sobre o projeto

Este projeto apresenta um guia passo a passo para configuração e utilização de Python, VS Code, Git e GitHub.

## Objetivo

Demonstrar, de forma prática e organizada, como preparar um ambiente de desenvolvimento, utilizar Git para controle de versões e publicar um projeto no GitHub.

## Tecnologias e ferramentas

- Python
- VS Code
- Git
- GitHub
